# 💬 Чат-бот для Dimario Bike Master

Готовий чат-віджет для вашого сайту (`dimarioshell-collab.github.io/bike-website`).
Працює повністю на фронтенді — без сервера, сумісний з GitHub Pages.

Бот вміє:
- показувати меню з послугами, цінами, процесом роботи, інфо про майстра і контактами;
- розуміти прості текстові питання («скільки коштує», «як записатись» тощо);
- провести користувача через міні-форму запису на консультацію (ім'я → телефон →
  послуга → зручний час → коментар);
- сформувати готовий текст заявки, скопіювати його в буфер обміну і відкрити ваш
  Telegram, щоб клієнту залишилось тільки вставити (Ctrl+V) і надіслати.

Дизайн повністю підхоплює стилістику вашого сайту (тьмяна майстерня, зелений
акцент `--accent`, шрифти Bebas Neue / Manrope / Space Mono).

## Встановлення (2 хвилини)

1. Скопіюйте файли `chatbot.css` і `chatbot.js` у папку сайту, поруч зі `style.css`
   і `script.js`.

2. У `index.html` додайте один рядок у `<head>`, після підключення `style.css`:

   ```html
   <link rel="stylesheet" href="style.css" />
   <link rel="stylesheet" href="chatbot.css" />   <!-- ← додати цей рядок -->
   ```

3. І один рядок перед закриттям `</body>`, після `script.js`:

   ```html
   <script src="script.js"></script>
   <script src="chatbot.js"></script>   <!-- ← додати цей рядок -->
   </body>
   ```

4. Готово. Кнопка чату 💬 з'явиться в правому нижньому куті на всіх сторінках,
   де підключені ці два файли.

## Як перевірити перед публікацією

Відкрийте `demo.html` у браузері (подвійний клік по файлу) — це ізольована
сторінка з тим самим чат-віджетом і темною темою сайту, без потреби
завантажувати весь проєкт.

## Налаштування під себе

Усі контакти й тексти — на самому початку файлу `chatbot.js`, у блоці `CONFIG`:

```js
const CONFIG = {
  botName: "DIMARIO BIKE",
  botSubtitle: "Бот-консультант · на зв'язку",
  telegramLink: "https://t.me/+YOs8HjJgr9hkMWZi",       // загальний Telegram
  telegramOrderLink: "https://t.me/+SpzKmo1Z16syNmIy",  // куди йде заявка
  phone: "+380631446701",
  phoneDisplay: "+38 063 144 67 01",
};
```

Список послуг (для меню й кнопок вибору послуги в заявці) — трохи нижче,
у масиві `SERVICES`. Ціни та тексти про процес/про майстра/контакти —
у константах `PRICING_TEXT`, `PROCESS_TEXT`, `ABOUT_TEXT`, `CONTACTS_HTML`.
Змінюйте текст прямо там — HTML-теги (`<strong>`, `<a>`) підтримуються.

## Важливо розуміти: як саме працює запис на консультацію

Ваш сайт — статичний (GitHub Pages), без бекенду. Тому справжня «пряма»
відправка повідомлення боту в Telegram із сайту без сервера технічно
неможлива без ризику для безпеки (довелося б публічно розкрити токен
Telegram-бота в коді сторінки, що небезпечно — будь-хто зможе його вкрасти).

Тому обрано найнадійніший варіант без сервера:
1. Бот збирає дані заявки в самому чаті.
2. При підтвердженні текст заявки **автоматично копіюється в буфер обміну**.
3. Відкривається ваш Telegram-чат — клієнту залишається вставити (Ctrl+V або
   довге натискання → «Вставити») і натиснути «Надіслати».

### Якщо захочете повну автоматизацію (заявка приходить сама, без участі клієнта)

Це можливо, але вимагає невеликого сервера-посередника (щоб не публікувати
токен бота у відкритому JS). Найпростіший варіант — безкоштовна serverless-
функція (наприклад, Cloudflare Workers або Vercel Functions), яка приймає
запит із сайту і сама відправляє повідомлення через Telegram Bot API.
Якщо потрібно — можу підготувати такий сервер окремим кроком; знадобиться
токен бота від @BotFather (той самий, що й для Telegram-бота із записом
на сервіс, який ми зробили раніше).
